# MedControl

## Problema
Idosos frequentemente esquecem de tomar medicamentos nos horários corretos.

## Solução
Aplicação CLI simples para cadastrar e consultar medicamentos.

## Público-alvo
Idosos, cuidadores e familiares.

## Funcionalidades
- Adicionar medicamento
- Listar medicamentos
- Remover medicamento

## Tecnologias
- Python
- JSON

## Instalação
pip install -r requirements.txt

## Execução
python src/main.py

## Testes
pytest

## Lint
ruff check .
